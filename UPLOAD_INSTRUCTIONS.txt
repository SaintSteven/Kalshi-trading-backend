Kalshi Trading Backend v1.4 — Edge Engine

Add to the ROOT of GitHub:
- edge_models.py
- edge_engine.py
- example_edge_analysis_request.json

Then apply the small main.py change in main_patch.txt.

After deployment:
1. /health should show version 1.4.0
2. /docs should show POST /edge-analysis
3. Test with example_edge_analysis_request.json

The Edge Engine measures:
- qualifying bets by minimum model edge
- one-contract profit and ROI
- estimated fees
- YES vs NO performance
- price bucket performance
- average model edge
- closing-line value when closing prices are supplied

Important:
This endpoint analyzes historical market records supplied to it.
It does not yet automatically retrieve historical Kalshi prices.
This remains paper-only.
